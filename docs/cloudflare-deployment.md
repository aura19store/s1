# Cloudflare deployment guard

Do not deploy without approval. From the project root, the supported command after approval is `npm run deploy:cloudflare`. It runs Wrangler using `wrangler.jsonc`; Wrangler's `build.command` removes old `.next` and `.open-next` output, runs a full OpenNext build, then verifies the generated Worker, bundled server handler, current admin assets, deletion API and PDF code. It embeds a SHA-256 fingerprint of the local build inputs in the admin layout and rejects a mismatch or changes to those inputs during the build. A failed build or verification prevents Wrangler from deploying. Do not run two builds or deployments from the same checkout concurrently.

Direct `wrangler deploy` using this configuration also reaches the build hook before Wrangler bundles or uploads the Worker, including with `--no-bundle`. However, Wrangler may first delegate to `opennextjs-cloudflare deploy`, which requires `.open-next` to exist before the hook runs; a completely clean checkout may fail at that earlier step. Use the supported npm command instead. No bypass flags or alternative Worker entry points are supported. A different `--config`, a redirected Wrangler configuration, direct API upload, modifications to the build tools or files after verification, or concurrent non-cooperating processes are outside this guard. The fingerprint covers the listed local source/config inputs, not dependencies, environment variables, runtime uploads, or a proof of what Cloudflare ultimately deployed. Review all local changes before building: a build uses the working tree, including uncommitted changes, not just HEAD.

If an interrupted build leaves `.open-next-build.lock`, first confirm no build is running, then remove that empty directory before retrying. This lock prevents overlapping invocations of the guard, not arbitrary programs that modify output during a deployment. The default OpenNext configuration has no remote cache override; changes to it require reviewing whether cache population happens before or after verification.
